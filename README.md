Simulador Bancário em Swift

Projeto desenvolvido durante o curso Open Academy — Introdução a Swift.

O objetivo foi praticar os conceitos básicos da linguagem Swift através da criação de um pequeno sistema bancário executado pelo terminal.

Funcionalidades
Criar novas contas
Login e logout
Visualizar dados da conta
Realizar depósitos
Realizar transferências entre contas
Verificar saldo insuficiente
Conta com acesso de administrador
Listagem das contas pelo administrador
Conceitos praticados

Durante o desenvolvimento, foram utilizados conceitos como:

Variáveis e constantes
Funções
Tuplas
Arrays
Optionals
guard let
switch
Estruturas condicionais
Closures
Manipulação de strings
Entrada de dados pelo terminal
